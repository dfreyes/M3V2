# M3ACT1: Exploratory Data Analysis of the Titanic

## Descripción

Notebook de análisis exploratorio de datos del Titanic. Examina la estructura y las estadísticas del conjunto de datos, revisa valores faltantes y utiliza visualizaciones para explorar la supervivencia según el sexo y la clase del pasajero.

## Archivos

- [M3ACT1 Assignment - Exploratory Data Analysis of the Titanic.ipynb](M3ACT1%20Assignment%20-%20Exploratory%20Data%20Analysis%20of%20the%20Titanic.ipynb): notebook con el análisis, gráficos e interpretaciones.

## Datos

El notebook carga el conjunto de datos CSV desde [este repositorio de datos](https://raw.githubusercontent.com/eugeniomorocho/ArtificialIntelligence/main/Datasets/titanic.csv), por lo que se necesita conexión a Internet para ejecutarlo.

## Cómo ejecutar

1. Instala Python y Jupyter Notebook.
2. Instala las bibliotecas utilizadas:

   ```bash
   python -m pip install pandas matplotlib seaborn jupyter
   ```

3. Abre el notebook en Jupyter o en VS Code y ejecuta las celdas en orden.

El notebook también puede visualizarse directamente en GitHub; sus celdas incluyen resultados y gráficos guardados.
